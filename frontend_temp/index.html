The Process

How It Works

Step 01 — Vision Analysis
Vision Analysis

Claude AI scans your uploaded photo using computer vision, identifying visible housing conditions — mold growth, structural damage, faulty plumbing, fire hazards, pest evidence, and electrical issues. Each observation is categorized by type (structural, plumbing, environmental, etc.) and assigned a confidence level based on what's visible in the photo.

Mold & Moisture Structural Damage Electrical & Fire Hazards Pest Infestation
Step 02 — Code Matching
Code Matching & Citation Verification

Every observed condition is cross-referenced against a real housing code database for your jurisdiction — currently Blacksburg, VA. Each matched violation includes the exact code section, a plain-English explanation, and the reasoning behind the match. Nothing is freely generated: every citation is verified against the actual database before it appears in your report.

Real database — not generated Exact code citations Blacksburg, VA jurisdiction
Step 03 — Complaint Generation
Complaint Generation

Verified violations are compiled into a formal complaint letter with accurate legal citations, ready to send to your landlord or file with local housing authorities. You also receive local enforcement contact information and a timestamped evidence log — everything you need to take action. All outputs are yours to download and keep.

Common Questions

FAQ

Is this legal advice?

No — informational only. Witness identifies and documents potential housing code violations to help you understand your situation. Consult a licensed attorney before taking formal legal action.

What jurisdictions are supported?

Currently Blacksburg, VA. The underlying architecture is modular and designed for expansion — additional jurisdictions can be added as the database grows.

Is my photo stored?

Your photo is uploaded temporarily to AWS S3 for processing only and is not retained beyond the analysis session. No images are stored permanently or shared.

What if the AI finds nothing?

You'll see a clear "no violations detected" result. This may mean the photo didn't capture a violation clearly enough, or the conditions shown don't meet the threshold for a code match in your jurisdiction.

How accurate is it?

All code citations are verified against a real housing code database — not freely generated by the AI. The matching step uses structured data, not language model output, to confirm each violation reference.

Can my landlord see this?

No. Your report is yours alone. Nothing is shared with your landlord, property management, or any third party. You decide if and how to use the generated letter.
